# 2 分钟演示视频 · 录制剧本

> 目标：**120 秒**讲清"ACE 是一个把安全下沉到执行层的 agent"，而且要**可复现** ——
> 全程 `--mock`，**不需要 API Key、不需要联网**，每一拍都写死输入，所以拍第二条也长一样。
>
> 这张剧本本身也是给读者的：所有输入都来自 `demo/record_demo.py` 里那几套固定剧本，
> 所以你可以自己跑一遍，看到与视频一致的画面。

## 硬约束（先读这条）

| 约束 | 为什么 |
|---|---|
| **全程离线 `--mock`** | 视频里绝不能出现 API Key（一次截图泄漏就够毁掉一个安全项目的可信度） |
| **拍前清场** | 关掉其他窗口/通知；终端里不出现真实用户名、家目录绝对路径、真实仓库名 |
| **不夸大** | 不说"绝对安全""无法绕过"。要说的是"**执行层仍然在，而提示词失败时它还在**"（见文末「不许出现的说法」） |
| **拍两条** | 一条完整版（120 s），一条 20 s 纯高光（给 README / 社交平台），都用同一套输入 |

## 录制前（5 分钟）

```bash
python ai_code.py --mock          # 先空跑一遍，确认离线可用、没有残留会话
```

- **终端**：Windows Terminal / iTerm / GNOME Terminal 均可，**字体等宽**，字号调到 16–18（手机上也看得清）。
- **尺寸**：**88 列 × 30 行** —— 与仓库里那几张演示图一致（`landing` 就是用 `--preview-width 88` 渲染的）。
- **编码**：UTF-8（Windows 上 `chcp 65001`，`ace.cmd` 已经替你做了）。
- **配色**：用深色主题；关掉透明/模糊（录屏压缩后会糊）。
- **清掉历史**：`ACE_NO_HISTORY=1 python ai_code.py --mock` —— 免得 ↑ 翻出你上一条真实会话。

## 分镜表（总 120 s）

| # | 时间 | 输入 | 屏幕上应出现 | 旁白（建议） |
|---|---|---|---|---|
| 1 | 0:00–0:12 | 启动：`python ai_code.py --mock` | 首屏面板：权限档 / 沙箱档 / 网络 / 审批 / 工作目录 / 上次会话；下面是分组菜单 + 底栏 | "大多数 agent 把安全写在提示词里。ACE 不是 —— 它有一层**独立的执行层**。" |
| 2 | 0:12–0:35 | `现在几点` | 模型 → **工具调用**（`datetime_now`）→ 回答 → 底栏状态更新 | "这是完整的模型 ↔ 执行层闭环，**离线、不需要密钥**。每一次工具调用都要过执行层。" |
| 3 | 0:35–0:58 | 先 `/permission readonly`，再 `帮我读一下 ~/.ssh/id_rsa 里的私钥` | **`403`** + 明确理由（项目外 / 敏感目标），工具**根本没执行** | "**这一段是整条视频的重点。** 模型要去读 SSH 私钥 —— 执行层在工具运行之前就拒绝了。不是提示词在请求它别读，是一个它说服不了的检查。" |
| 4 | 0:58–1:18 | `/permission write`，然后 `帮我改代码，往笔记里加一行` | 写入卡片：**上色 diff**（+1 −0）+ 一行工具时间线 + `exit 0`；随后 `/undo` | "改动是可看见的；而任何一次写入之前都先建了**物理快照**，`/undo` 一键回去。" |
| 5 | 1:18–1:33 | `/status` | 模型 / 权限 / 沙箱 / 网络 / 上下文占用 / 本轮成本 | "它也说清自己现在**处在什么边界里** —— 而不是让你猜。" |
| 6 | 1:33–1:55 | 切到 [`docs/security/SECURITY-FAQ.md`](../docs/security/SECURITY-FAQ.md)（浏览器或编辑器） | 11 问；高亮两问 | "我们写了一整篇 FAQ 讲**自己挡不住什么**。比如无人值守时 fail-close 的是'要问人的那些'，**不是'危险的那些'**；再比如快照**不覆盖**凭据文件。" |
| 7 | 1:55–2:00 | 回到首屏 | —— | "**安全不该住在提示词里。** ACE 把它放在模型够不着的一层。" |

> **拍砸了怎么办**：3 号镜头如果 `403` 出现太快/太慢，用同一句输入重拍即可 ——
> mock 是脚本化的，输出不随机。

## 三种录法

| 方式 | 命令 | 适合 |
|---|---|---|
| **终端录制（推荐）** | `asciinema rec ace.cast` 然后照分镜输入 | 体积最小、可复制文本、能贴进 README 当替代品 |
| **屏幕录制** | Windows: `Win+Alt+R`（Xbox Game Bar）/ macOS: `Cmd+Shift+5` | 要有鼠标与窗口动作时 |
| **静帧** | `python ai_code.py --mock --preview --preview-width 88` | 只要首屏；仓库里 `demo/demo_landing.svg` 就是这么来的 |

要让**仓库里的演示图**跟着更新（版本号变了必须重录，否则 `test_all [68]` 会红）：

```bash
python demo/record_demo.py --check     # 先看有没有腐化
python demo/record_demo.py --session happy    # 其余：blocked / diff / landing
```

## 剪辑注意

- **把 3 号镜头（403）放在前半段。** 那是唯一"别的 agent 做不到"的画面，别埋在中段。
- **别加速终端。** 打字机效果本身就是产品体验的一部分；要压缩就剪掉等待间隙，不要整体快放。
- **烧字幕，别只靠旁白。** 很多人在静音下刷到这条；把 1/3/6 三拍的旁白烧成字幕。
- **结尾留 3 秒静止**，别在最后一帧切断。
- 导出 **1080p / H.264 / AAC**，目标 15–25 MB。

## 不许出现的说法

这个仓库的规矩是"拿不准就写拿不准"。视频里同样：

| 别说 | 改成 |
|---|---|
| "绝对安全" / "无法绕过" | "**提示词失败时，执行层仍然在**" |
| "完整沙箱隔离" | "默认是**进程内策略**；真正的边界是 `--sandbox job` / `--sandbox docker` 加最小权限账户" |
| "能回滚一切" | "写前快照能回滚；但 `.git` / `.guardian` / `.ace_sessions` 与**凭据文件不在快照里**" |
| "无人值守更安全" | "无人值守时**要问人的那些动作会直接失败**，不需要审批的写/执行工具照跑 —— 别把'CI 里没报错'读成'CI 里很安全'" |

上面四条的完整口径都在 [`docs/security/SECURITY-FAQ.md`](../docs/security/SECURITY-FAQ.md)。

# 键位对照：Claude Code ↔ ACE（v3.38.0）

> 这张表是**核实过**的：Claude 那一列来自官方文档与 changelog（`code.claude.com/docs`，
> 逐条带来源，原始抓取留在 `cc_research/`），ACE 那一列来自本仓库的
> `ui/ace_keys.APP_KEYMAP` 与 `tui/app.py` 的实现。
> 判定口径：**能在组件界面里真按出来**才算"有"；只在帮助里写了不算。

## 一、全局 / 会话键

| 键 | Claude Code | ACE（组件界面） | 备注 |
| --- | --- | --- | --- |
| `Ctrl+C` | 中断；空闲时清空 → 再按退出 | ✅ 中断（两段式）；空闲时「再按一次退出」 | 输入框把 Ctrl+C 绑成了"复制"，ACE 用**优先级键位**抢回来 |
| `Ctrl+D` | 退出（空输入）；有文本=删右侧字符 | ✅ 同 | 在 `ChordInput._on_key` 里判空，非空交回输入框 |
| `Ctrl+L` | 重画屏幕 | ✅ 清转写区（会话保留） | 语义等价：都是"把屏刷干净" |
| `Ctrl+O` | 详细转写视图 | ✅ 展开最近一次被折叠的输出 | ACE 的折叠对象是工具卡片/diff |
| `Ctrl+R` | 反向搜索历史 | ✅ 模糊历史选择器（跨会话） | Claude 全屏版也是"搜索对话框" |
| `Ctrl+B` | 把 Bash / 子代理丢后台 | ⚠️ 工具看板开关 | ACE 没有"后台任务"这条通路，不假装有 |
| `Ctrl+T` | 任务清单 | ✅ 任务树（`/tasks`） | Claude 明确说"不是后台任务视图"，一致 |
| `Ctrl+G` / `Ctrl+X Ctrl+E` | 外部编辑器 | ✅ 同（`$VISUAL`/`$EDITOR`） | Windows 无 `$EDITOR` 时退 `notepad` |
| `Ctrl+V` / `Alt+V` | 粘贴剪贴板图片 | ✅ 同（**仅 Windows 剪贴板**） | 非 Windows 诚实提示"拿不到图"，不假装支持 |
| `Ctrl+S` | 暂存 / 取回草稿 | ✅ 走 `/stash` | ACE 的 stash 是同一份会话状态 |
| `Ctrl+Z` | Unix 挂起 | ❌ 不做 | 终端自己的语义，ACE 不抢（撤销用 `Ctrl+_`） |
| `Esc` | 中断 / 关对话框 / 权限框里=拒绝 | ✅ 同 | 权限框里 Esc = 拒绝（带备注时回传理由） |
| `Esc Esc` | 有文本=清空草稿（存历史）；空=回退菜单 | ✅ 同 | 回退菜单给"只退对话 / 回退文件到快照"两条路 |
| `Shift+Tab` | 权限模式环（4–6 档） | ✅ 环：readonly → write → full（进 `full` 二次确认） | Claude 有 plan/auto 等档，ACE 的档位体系由执行层定义，不硬凑 |
| `Tab` | 接受补全；权限框上=加备注 | ✅ 同 | 补全在输入框上，备注在授权模态里 |
| `↑`/`↓`、`Ctrl+P`/`Ctrl+N` | 历史；查找模式里跳命中 | ✅ 同 | 查找模式（`Ctrl+F`）下 `Ctrl+N/P` 跳下一处/上一处 |
| `Alt+P` | 切模型 | ✅ `Alt+M`（ACE 用 M，避开终端把 Alt+P 吃掉的情况） | 也可直接 `/model` |
| `Alt+T` | 开关思考过程 | ✅ 同（= F2） | |
| `Ctrl+X Enter` | 排队发送（不打断） | ✅ 同 | |
| `Ctrl+Enter` / `Ctrl+X Ctrl+S` | 立刻发送（打断当前轮） | ✅ `Ctrl+X Ctrl+S` | `Ctrl+Enter` 很多终端送不出来，和弦那条更可靠 |
| `?`（空输入） | 帮助面板 | ✅ 同（F1 也行） | 有字时就是普通问号 |
| `PgUp`/`PgDn` | 半页滚动 | ✅ 同 | |

## 二、行编辑（readline/emacs）

| 键 | Claude Code | ACE | 备注 |
| --- | --- | --- | --- |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾 | ✅（输入框自带） | |
| `Ctrl+K` | 删到行尾（进 kill buffer） | ✅ 同 | 输入框自带这一条，但它**不填 kill ring** → ACE 自己接 |
| `Ctrl+U` | 删到行首（进 kill buffer） | ✅ 同 | 同上 |
| `Ctrl+W` | 删到前一个**空白**（`src/utils/foo.ts` 一下全删） | ✅ 同 | 与 `Alt+B` 的边界**故意不同**，两边都是一样的两条口径 |
| `Ctrl+Y` | 粘回刚删掉的 | ✅ 同 | kill ring 只有一格（够用；不做 `Alt+Y` 轮换） |
| `Alt+B` / `Alt+F` | 按字母数字边界走词 | ✅ 同 | `_ . /` 都算分隔符 |
| `Alt+D` | 删到词尾 | ✅ 同 | |
| `Alt+Backspace` / `Ctrl+Backspace` | 删前一个词 | ✅ `Alt+Backspace` | |
| `Ctrl+_` / `Ctrl+Shift+-` | 撤销上一次输入编辑 | ✅ 同 | **不是** `Ctrl+Z`（那是挂起） |

## 三、多行输入

| 方式 | Claude Code | ACE |
| --- | --- | --- |
| `\` + 回车（续行） | ✅ 所有终端可用 | ✅ 同 |
| `Ctrl+J` | ✅ 所有终端 | ✅ 同 |
| `Alt+Enter` / `Shift+Enter` | ✅（取决于终端） | ✅ 同（终端送不出来时用上面两条） |
| 直接粘贴 | ✅ 大段折叠成 `[Pasted text #N]` | ⚠️ 多行粘贴本身可用；**折叠还没做**（列在待办里） |

## 四、前缀

| 前缀 | Claude Code | ACE |
| --- | --- | --- |
| `/` | 斜杠命令 / 技能（句中也能补全，回车照发） | ✅ 同（`ui/ace_menu` 的同一套模型） |
| `@` | 文件引用 | ✅ 同（另有 `@lang` / `@skill` / `@folder`） |
| `!` | Shell 模式 | ✅ 同（走执行层闸门，不是裸跑） |
| `#` | **已被上游移除**（v2.0.70，改让模型编辑 CLAUDE.md） | ❌ 不实现 —— 不追一个已经删掉的功能 |

## 五、我们**没做**、以及为什么

| 项 | 原因 |
| --- | --- |
| `Ctrl+B` 后台化 Bash / 子代理 | ACE 没有"把前台任务转后台"这条通路；假装有比没有更坏 |
| 检查点/回退的 6 个细分动作（只恢复代码 / 只恢复对话 / 从这里总结…） | ACE 有 `/rewind`（对话）与 `/rollback`（文件快照）；"总结到某处"要动摘要链路，另行评估 |
| 转写视图里的 `less` 键（`/`、`n`、`g`、`[`） | ACE 的组件界面用**组件**滚动（滚轮/翻页/`Ctrl+F` 查找）而不是分页器；`[` 把会话打进原生回滚区这条依赖备用屏幕之外的渲染方式 |
| `:` emoji 短码、拼写检查、语音输入 | 与"编码代理"这条主线无关，不做 |
| `Ctrl+X Ctrl+B`（绕开 tmux 前缀的后台键） | 同第 1 条 |
| 拖放图片 | 上游文档里也**没有**这条（只有剪贴板粘贴与 `@` 文件引用），不追未证实的交互 |

## 六、ACE 有、Claude 那边没有对等物的

| 键 | ACE 的用法 |
| --- | --- |
| `Shift+Tab` 的"进 full 要按两次" | ACE 的 `full` 档 = 不再逐次审批，一个快捷键不该解除全部审批 |
| `Ctrl+X e/t/d` | 全部展开 / 任务树 / 本轮改动（和弦家族，占用小） |
| `F1` / `F2` | 帮助浮层 / 思考过程开关（终端里 F 键比 `Ctrl+字母` 宽裕） |
| `Ctrl+O`（折叠语义） | 展开的是"最近一次被折叠的工具输出/diff"，与 `/expand` 同源 |

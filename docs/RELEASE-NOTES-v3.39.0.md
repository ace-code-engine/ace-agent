# v3.39.0 —— 主页 · 功能面板 · 回溯两段式（交互设计由我们自己定）

> 这一版做的是**信息层级**，不是又加几个键。顺序、位置、默认值都有理由，写在
> `docs/HOME-DESIGN.md` 里；键位对照表同步更新到 `docs/KEYMAP-CLAUDE-PARITY.md`。

## 一、主页（会话区的第一块）

```
ACE 3.39.0 · deepseek-chat · readonly

  接着上次
  ▶ 继续上次：昨天（4 轮）        回车继续 / ↑↓ 选别的

  开始
    新对话                        清空上下文并开一段新会话（Alt+N）
    历史对话（3 条）               挑一条继续（Alt+H）
    命令与键位                     /help 或 F1

  能力（这里改，立刻生效）
    思考强度   中                  auto → 低 → 中 → 高（Alt+T 循环）
    联网思考   开                  回答前先搜网、列来源（Alt+W 切换）
    回答语言   中文                中文 / English / 日本語（Alt+L 切换）
    权限档     readonly            只读 → 可写 → 全权（Shift+Tab）
    模型       deepseek-chat       换模型 / 换提供商（Alt+M）

  我们独有的
    回溯（2 个快照）               退对话 / 回退文件（Esc Esc）
    任务树与改动                   /tasks · /diff · /report
    本轮报告                       /report 导出这段会话

↑↓ 选 · 回车执行 · 也可以直接在下面打字（/ 命令 · @ 引用 · ! 命令 · F1 帮助）
```

- **排序不是随手排的**："继续"第一（绝大多数人打开就是想接着上次说）；能力开关第二
  （必须在开始之前定好，跑到一半才发现要改就得重来）；"我们独有的"第三（需要时才找，
  常驻只会挤掉前两类）。
- **每行都写当前值 + 怎么改**：主页一半的价值在"现在是什么"，另一半在"不用去别处查怎么改"。
- **做成会话区的第一块，不是独立页**：打字后它自然滚上去，`Alt+1` / `/home` 再看一眼。
- **`--preview` 画的就是它** —— 预览与真首屏同一份渲染，"预览好看、真跑不是这样"是最坏的不一致。

## 二、能力开关（每条都落在提示词或执行层，不是装饰）

| 开关 | 档位 | 键 | 实际影响 |
| --- | --- | --- | --- |
| **思考强度** | `auto` → 低 → 中 → 高 | `Alt+T` / `/effort` | 系统提示增量：低=直接给结论；中=先说取舍；高=列假设与备选并说明为什么否掉别的 |
| **联网思考** | 开 / 关 | `Alt+W` / `/net` | 提示里加"先搜再答 + 列出来源 + 当前年月"，避免拿旧知识答新问题 |
| **回答语言** | 中文 / English / 日本語 | `Alt+L` / `/lang` | 提示里加语言段（代码标识符保持原样）；**界面语言一起切** |
| 权限档 | readonly → write → full | `Shift+Tab` | 执行层（进 `full` 需二次确认） |
| 模型 | 任意 | `Alt+M` / `/model` | 选择框，可输入过滤 |

三个刻意的决定：

1. **`auto` 是默认档且不加任何提示词** —— 默认行为不该被我们的偏好污染。
2. **关键词逃生门**：输入里写 `ultrathink` / `认真想` → **这一轮**按最高档，用完即清。
   想让它多想一会儿时敲一个词就行，不必先去改设置。
3. **思考强度与 `/thinking` 是两条轴**：那条管"显示不显示思考过程"，这条管"想多深"。

## 三、新对话 与 历史对话

- **`/new`**：**换一个新会话文件** + 清空上下文。与 `/clear` 的区别写清楚 ——
  `/clear` 只清上下文（还是同一次会话），`/new` 让它在历史里成为独立的一条。
- **`/sessions`**：历史对话列表（时间 · 轮数 · 首句），选择框里可输入过滤。
- 主页把最近一条直接摆在"继续"那一行，省掉一次进列表的操作。

## 四、回溯：两段式

```
Esc Esc（空输入）
  ├─ 第一段：回到哪一条（从最近的输入里选，可过滤）
  └─ 第二段：退什么 —— 退对话并回退文件 / 只退对话 / 只回退文件到最近快照 / 算了
```

- **分两段的理由**：`退对话两轮` 与 `回退文件到快照 3` 是两类无法比较的东西，并排在一个
  列表里只能靠读整句判断；
- **能力门控**：没有快照就不给"回退文件"（给了也只会报错）；
- **默认项是最完整的那个，但"算了"永远在**。

## 五、顺手对齐的三个细节（核实上游之后改的）

- **CJK 逐字走词**：`Alt+B` 在中文里现在一个字一个字退（上游用分词器也是这个口径）。
  不特判的话，一句中文会被当成一个超长词一步跳过去。
- **kill ring 升级成 10 格**：连续删累积成一格（`Ctrl+W` 三次 → 一个 `Ctrl+Y` 全粘回），
  `Alt+Y` 往回翻更早删掉的。
- **和弦超时对齐 1 秒**。

## 六、启动器修复（这次顺手查出来的真故障）

`ace.cmd` 里原来有**中文注释**。cmd.exe 按字节偏移跟踪自己在批处理文件里的位置，配合
`chcp 65001` 时这个记账会错位 —— 症状是 cmd 从**行中间**继续读，把注释的尾巴当成命令执行，
用户看到的就是：

```
'量（你显式指定的那套）' is not recognized as an internal or external command
```

现在 `ace.cmd` **纯 ASCII**（注释与提示都改成英文，中文提示归 Python/i18n 那份），
并加了守卫：**批处理文件不允许出现任何非 ASCII 字节**。

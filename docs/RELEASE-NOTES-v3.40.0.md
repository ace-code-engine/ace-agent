## 一、补全浮层：按 ↓ 文字不动 / 提示看不到尽头

**根因不是样式，是渲染**：`render_menu` 只渲染**前 N 条**。选中项走到第 N+1 条之后，
光标就跑到看不见的地方去了 —— 用户看到的是"我按了键，什么都没发生"。

现在渲染的是**窗口**：

| 规则 | 为什么 |
| --- | --- |
| 选中项**永远在窗口里** | 这是"按了有反应"的底线 |
| 窗口**黏**（没越过边界就不动） | 否则每按一下整屏都在跳，比不动更晕 |
| 上面还有内容 → 「↑ 还有 N 项」 | 不然用户以为列表就这么长 |
| 提示行**恒为最后一行** | 它是"这里怎么操作"的唯一说明，被裁掉等于说明书撕了一半 |
| 高度**按内容设**，封顶屏幕四成 | `height: auto` + `max-height` 会把最后一行裁掉；封顶则保证不吃掉转写区 |

## 二、左上角那个圈 = 回主页

- 点左上角那一块（图标及其右侧留白）回主页；`Alt+1` / `/home` 是等价的键盘入口。
- **三层都接**：图标自己的 `on_click`/`on_mouse_down`、顶栏左侧一块、App 级按**事件坐标**兜底 ——
  终端的命中测试在不同环境里把点击报给谁并不一致，赌一层迟早会"点了没反应"。
- **按下即走**（部分终端只报 mouse-down，等抬手就永远不会触发）。
- 判定不用 `self.mouse_position`：它靠 MouseMove 更新，而点击不一定带一次移动 ——
  拿它判会时灵时不灵。用事件自带的屏幕坐标。

> **需要真机确认**：无终端测试台（`run_test`）把鼠标事件直接投给 Screen，点不到顶栏那一行。
> 逻辑已用**事件桩**验过（段 `[66]`），真终端里 Textual 会把点击送给图标 —— 与它内置的
> 命令面板图标是同一机制。请在你自己的终端里点一下确认。

## 三、会话管理：一眼看出"是哪一段"

- 会话日志新增头事件 `session/start`，记下**项目根目录**（这段会话是在哪个文件夹里开的）。
- 摘要暴露 `project` / `root`，列表行变成：

```
1. [ace] 今天 14:20 · 6 轮 · 帮我把主页的分区顺序调一下
2. [my-project] 昨天 09:03 · 3 轮 · 这个报错怎么修
```

只给时间和首句的话，同一天在三个项目里聊过就完全认不出来 —— 文件夹比时间更能定位一段对话。

- 主页顶行与顶栏副标题也带上**当前文件夹**（像 dsh 那样把"在哪个文件夹里"摆在明面上）。

## 四、思考强度：按上游口径补齐到五档

| 档位 | 符号 | 提示词增量（要点） |
| --- | --- | --- |
| `auto` | `○` | 不加任何话（默认） |
| `low` | `◐` | 直接给结论与最小改动 |
| `medium` | `●` | 先说清关键取舍，只说影响结论的那几句 |
| `high` | `◉` | 列假设与备选、逐条权衡、说明为什么否掉别的 |
| `max` | `◆` | 在高之上：先重述问题、说清怎么验证、点明不确定处 |

- 关键词逃生门（`ultrathink` / `认真想`）落**最高档**，用完即清。
- **选择框里的强度行**：`/model` 的选择框底部多一行强度，`←/→` 就地调 —— 换模型与调强度
  本来就是同一个决策（"这次要它多用力"）。这两条键是**优先级键位**，否则会被过滤输入框
  吃成"移动光标"。

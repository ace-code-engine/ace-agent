## 2. 关键决策（可审计）

- **D-1** 发布触发 = 手动 `workflow_dispatch`；v3.7.0 是第一个与 GitHub Release 绑定的 tag（仓库本地已有 v3.3~v3.6 里程碑 tag，README 原"未打 git tag"为过时描述，已修）。
- **D-2** 产物矩阵 5 档（win-amd64 / linux-amd64 / linux-arm64 / darwin-amd64 / darwin-arm64），`CGO_ENABLED=0` 交叉编译 + windows/ubuntu/macos-14 原生 `--version` 冒烟；发布幂等（已存在 Release 只 upload 不重建）。
- **D-3** `ace --install-executor` 用 stdlib urllib（不新增依赖），`ACE_EXECUTOR_BASE_URL` 支持镜像；下载后跑 `--version` **自校验才算成功**，绝不假成功。
- **D-4** 语义不变：job/docker 档拿不到边界仍 503 不静默回退；`--sandbox off` 顺带用执行器、起不来静默回落的旧行为保留。
- **D-5** 三份安全文档角色分离，不合并：根级 `SECURITY.md`（漏洞报告策略）、`docs/SECURITY-AUDIT.md`（历史审计）、`docs/SECURITY-MODEL.md`（机制说明，由 README 拆出）。
- **D-6** README「项目结构」折叠保留在 README（CONTRIBUTING 以它为权威树），不搬走。
- **D-7** 版本号展示全部改由 `version.py` 注入：横幅 `{ver}` 占位（三语言 locale），杜绝下次再硬编码漂移。

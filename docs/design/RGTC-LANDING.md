## 0. 一句话

> 把安全的**对象**从"命令/工具名"换成"世界的三条性质"：**世界可重建（I1）· 意图可归属（I2）·
> 范围可核对（I3）**。三条成立时，agent 做什么都不需要被预先枚举 —— 于是"保留全部能力"与
> "安全"不再互斥，评价指标也从"拦掉多少危险命令"变成两个可测的数：**漏报 / 误报**。

这份立项卡只做**它的落地部分**，并且明确划掉本方案自己承认解决不了的东西（见 §6）。

## 2. 语言与组件决策（先定这个）

**决定：不引入任何新语言，不引入 C++。**

| 做什么 | 用什么 | 为什么 |
|---|---|---|
| 判定、策略、台账、授权令、来源归属 | **Python（纯 stdlib）** | 与执行层同一个进程、同一套 `test_all` 纪律；HMAC/JSON/路径判断都在 stdlib 里，零新依赖 |
| 纯计算（指纹、哈希、去重、事件索引） | **已有的 Rust `engine/`** | 它今天的边界就是"只算不裁"（`engine/README.md`）；扩大它的角色＝破坏这条边界，所以**只**接纯计算 |
| 真需要**进程边界**时 | **已有的 Go `executor/`** | Job Object / 容器已经在那一侧；不另造一个"内核进程" |
| 影子平台的廉价复制（若 RG-05b 通过成本门） | **Python + `ctypes`** 调 ReFS 块克隆 | 一个 API 调用，不需要新工具链；Rust 侧只做指纹 |

三条**否决**理由，写下来免得以后有人再提：

1. **不新增语言**：ACE 已经有三套（Python / Rust / Go）且各有明确边界；第四套只会带来第四条发布链
   （又一条"本地不可验证"的路，本仓库在这上面已经红过五次）。
2. **不用 C++**：这里没有性能诉求需要它（真需要就把活交给已有的 Rust 引擎），而它会引入构建工具链、
   ABI、跨平台发布三个新变量。
3. **不把"内核"写成又一个 Python 模块**：agent 与执行层**同进程、同用户**，同进程的东西不构成信任边界
   （见 §3）。

## 3. 座位（seat）在哪 —— 本卡对原方案最大的一处修改

原报告的核心主张之一是"席位分离"：承载信任的机制必须住在被信任对象够不着的地方。
今天 ACE 的实情（已核实）：

- `core/guardian.py:91`：`self.store = project_root / ".guardian"` —— **在项目目录里**；
  `:101-106`：签名密钥落在 `.guardian/signing_key`。
- `core/sensitive.py:92-98`：`AGENT_STATE_DIRNAMES = {".guardian", ".ace_sessions", ".agent_flywheel",
  ".poc_reports"}`，理由原文就是"agent 改一行 `meta.json` 就能让 `verify_snapshot` 失效"。
- `tools/file_ops.py:102` → `_resolve_target_path` → `sensitive_target`：**读写都过这道判据**
  （`test_all.py:1889/1912` 有断言）。这道守卫是 2026-09-25 的 `b6aeede` 进来的。

**结论**：今天保护信任锚的是一道**路径判据**，而路径判据正是本方案论证"补不全"的那一类东西。
但**修法不是写一个内核模块**：

> 座位 = **工作区之外的、由操作系统权限保护的状态目录**（数据层），加上**已有的进程边界**
> （需要在同一进程里做不了的事时，走 `executor/`）。

同用户、同进程的 agent，靠文件位置**不能**获得绝对边界 —— 这一点必须写在文档里而不是含糊过去。
真正的边界仍是"agent 够不着工作区外"这条**执行层的既有约束** + OS ACL；进程隔离是加强项，不是本卡的前提。

## 4. 工作包

每个包：改动点 / 可证伪验收 / 风险 / 回滚 / 规模。**全部按"一个包一个可独立回滚的提交"落地。**

### RG-01 · 信任锚外移（S）—— **已实施**

- **改动**：`core/guardian.py` 的密钥路径解析改为**工作区之外的锚目录**
  （Windows `%LOCALAPPDATA%\ace-agent\state\<sha256(项目绝对路径 normcase)[:16]>\signing_key`；
  POSIX `$XDG_STATE_HOME` 或 `~/.local/state` 同构），根目录可用构造参数 `anchor_dir` 或
  环境变量 `ACE_ANCHOR_DIR` 注入。**快照仍留在 `.guardian/snapshots/`**（那是数据不是锚）。
- **实施记录（含对规划的一处修正）**：
  1. 规划里写的是"旧密钥保留但不再使用" —— **错**，已改为**搬完即删**。只拷不删等于把同一把密钥
     继续留在 agent 可写处，锚白搬（这正是"实测比设计更有话语权"的一例：先写了探针才看出来）。
     删除前先写锚 + 读回校验；删不掉就大声告警（此时边界并未真正建立）。
  2. 锚不可用时 `snapshot()` **直接抛错拒绝**（走执行层既有的"快照不可用 → 503"），
     而不是生成一份未签名快照 —— 未签名快照的摘要可以随内容一起被改，等于把安全网变装饰。
  3. 另补一处 fail-open：快照**带签名**、而当前拿不到密钥时，`verify_snapshot()` 从原来的
     "跳过签名只比摘要"改为**直接拒绝**（原文：拿不到密钥就说拿不到）。
  4. POSIX 下密钥文件 `chmod 0600`（Windows 靠 `%LOCALAPPDATA%` 的 ACL）；设不上只告警不中断。
- **验收（可证伪，全部已落地为 `test_all` 段 `[71]` 的 RG-01a~g）**：
  1. 迁移：`anchor_migrated=True`、锚里是同一把密钥、**项目内那份已不存在**；
  2. 迁移后老快照 `verify_snapshot` 仍为 true；
  3. 锚路径不以项目路径为前缀；
  4. **伪造不成立**：改副本 + 修 `meta.json` 摘要 → 仍判坏快照（项目内已无密钥可重签）；
  5. 攻击者自带一把密钥重签 → 仍不通过（锚里那把才是真的）；
  6. 拿不到密钥时拒绝验证带签名的快照；
  7. 锚不可用 → `snapshot()` 抛 `SnapshotError`（fail-close）。
- **实测对照（探针 `_rel_test/rg01_probe.py`）**：修复前"改内容+修摘要+用项目内密钥重签"
  → `verify=True`（安全网可伪造）；修复后同一操作 → `verify=False`（签名校验失败）。
- **顺带修正的文档**：`docs/SECURITY-AUDIT.md` 的 SEC-010 记录描述的
  `resolve_signing_key()` / `ACE_SIGNING_KEY` / `~/.ace/snapshot_signing_key` /
  `get_stats()["snapshot_signing"]` **在代码里 0 命中**，而实际把密钥放在了项目内 ——
  该段已加勘误（描述的设计未落地，且与代码事实相反）。
- **风险**：低。**回滚**：`git revert` 该提交（迁移只搬不删旧快照，锚里的密钥是数据的副本）。

### RG-02 · 事件台账链式签名（S）

- **改动**：`cli/ace_sessionlog.py` 每条事件加 `mac = HMAC(anchor, seq ‖ prev_mac ‖ canonical(body))`；
  `/audit` 增加整链校验；`seq` 断裂检测已有（`test_all` E4）。
- **验收**：
  1. 改一行内容 → 链断，且指出是哪条 `seq`；
  2. 删中间一条 → `seq` 断 + 链断；
  3. 尾部追加伪造行 → 无法生成有效 `mac`；
  4. **老日志（无 mac）→ 如实报"不可核验（早于本版）"**，既不判 ok 也不判失败（不静默降级）；
  5. 量一次开销：每事件 HMAC < 50 µs（**量出来的数写进卡里**，不写"应该很快"）。
- **风险**：低。**回滚**：签名开关（默认开）关掉即回到 append-only。

### RG-03 · 来源归属：把注入从"越权"降级为"噪声"（M）

- **改动**：
  - 工具结果打来源标签：`file_read` / `search` / `parse_document` / `kb_*` = **EXTERNAL**；用户输入 = **USER**；
    子代理继承父标签；
  - `execution_layer.py` 的 `_stage_permission` 增加判据：写类动作**没有 USER 侧引用 → 升级**；
    引用只来自 EXTERNAL → **升级**；
  - `run_tool_direct()`（`!cmd` / `/review` 回填那条路）**同一判据** —— 否则又是一个绕过口
    （v3.42.0 刚修过同类"绕过执行层"的缺陷）。
- **验收**：
  1. 只引用外部内容 → escalate（对应原型 ATK-1 的形状）；
  2. 无引用 → escalate（ATK-3 形状）；
  3. 用户明确指示的编辑/清理/删除 → 不被误伤；
  4. **已知逃逸必须测出来并记档**：引用一张真实但**不相关**的用户观测单 → 仍通过。
     这条**写成"通过但记档"**，不许写成"已拦住"（§6）；
  5. 误报率：真实会话日志回放，量"原本 auto 现在 escalate"的比例。
- **风险**：中（误报上升）。**回滚**：开关默认 off，先只统计不改裁决；数据够了再开。

### RG-04 · 可逆性分类器（M 测量版；翻判另开 RG-04b）

- **改动**：新增 `core/ace_recovery.py`，分类 `GIT / SNAPSHOT / REGENERABLE / NEVER / UNKNOWN`，
  事实全部来自 ACE 已有能力（git 跟踪状态、`EXCLUDE_DIRS`、能否建快照）。
  **第一版只把分类写进日志与 `/audit`，不改任何裁决。**
- **前置门（先测后改）**：跑真实会话 + 全量测试，产出"当前被 deny/escalate、而分类器会判可逆"的清单，
  **逐条人工看**，产出一张"要退化成 NEVER 判据的黑名单条目"表。
- **验收**：① gitignore 目录**不得**自动判 REGENERABLE（可再生要白名单，不能拿"被忽略"当"可再生"）；
  ② 反例测试：`rm -rf` 一个被 gitignore 但不可再生的目录 → 必须 UNKNOWN → escalate；
  ③ 清单里每一条都有结论（无"待看"）。
- **风险**：低（只读）。**规模**：测量版 M；翻判版（RG-04b）L，且只在清单支持时才开。

### RG-05 · 授权令（M/L）与影子平台（L，先过成本门）

- **RG-05a 授权令**：`mandate = (intents, roots, recoveryFloor, irreversibleQuota, ttl)`，用 RG-01 的锚签名。
  验收直接翻原型 ATK-6/7/8：额度用尽 → 问人；越出 roots → 问人；自签/篡改 → 拒。
  收益是弹窗从 O(步数) 到 O(任务数)；**roots 与额度是承重件**，不是装饰。
- **RG-05b 影子平台**：**先量成本，不达标就不做。**
  - 成本门：在真实工作区量"复制 + 跑 + 前后指纹"，建议阈值 **p50 ≤ 300 ms**（依据：本工作区实测
    347 文件 / 11.7 MB 的全量复制 159 ms、建后校验 1.9 s；ACE 真实规模是 1903 文件 / 34.5 MB）。
  - Windows 上没有 overlayfs/APFS clone，廉价复制需要 **ReFS 块克隆**（`ctypes` 调
    `FSCTL_DUPLICATE_EXTENTS_TO_FILE`）；拿不到就**不做**，或只对"未纳入 VCS 的目标"做小范围影子。
  - **明确禁止**：不依据影子放开任意代码执行。原型的外部落点检测是"对 argv 做正则"
    （`rgtc_kernel.js:705-726`），运行时拼出来的路径（`os.homedir()`、`process.env.TEMP`）看不见 →
    会把"写到了工作区外"判成"可逆且在范围内"。所以 `_FORBIDDEN_RULES` 里 `python`/`npm` 那条
    **保留**，直到有真正的强制层（容器/overlay）。

## 6. 明确不做（写下来，免得以后被当成"待优化"）

1. **不解决 I2 的语义归属**：模型可以引用一张真实但**不相关**的用户观测单。这是语义问题，不是密码学问题。
   本卡只能把攻击面从"任意注入"缩到"必须存在一张真实用户观测单"。**这是已知逃逸，不是 TODO。**
2. **不批量删除 `core/ace_execpolicy.py` 的 `_FORBIDDEN_RULES`**：它们的定位本来就是"防线之一，不是边界"。
   退一条要有一条的证据（G2）。
3. **不在同进程里造"内核座位"**：同进程同用户不构成边界（§3）。需要强隔离时走 `executor/`。
4. **不引入第四种语言、不用 C++**（§2）。
5. **不搬快照目录**：动它等于同时动 `/undo`、`/rollback`、`gc` 与一堆既有断言，收益却与 I1 无关。

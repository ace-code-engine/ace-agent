# v3.36.0 —— 交互重构：忙时排队 · 两段式中断 · 授权模态 · 作用域键位

> 旧手感是**阻塞式问答**：回车之后整个界面被这一轮占住 —— 打字没用、停不下来、
> 授权要手打 `2`、键位靠记。这一版把"这一轮处于什么状态、此刻按下去会发生什么"
> 抽成一层纯模型，再把组件界面重写在它上面。

## 一轮的状态机

```
idle ──submit──▶ busy ──finish──▶ idle（有排队就立刻接着跑）
                   │
                   ├─ 再来一条输入 → queued（不是丢掉，也不是排队等死）
                   ├─ interrupt   → requested（跑完当前这一步就停）
                   │                   └─ 再按一次 → forced（放弃本轮，界面立刻可用）
                   └─ 需要授权    → permission（≥200ms 之后的答案才算数）
```

| 旧手感 | 现在 |
| --- | --- |
| 跑起来之后界面整个卡住，打字没用 | **忙时输入不丢**：回车入队（底栏显示"队列 n"），这一轮结束**自动接着跑** |
| 想停只能 Ctrl+C 把进程带走 | **两段式中断**：一下"跑完当前步就停"，再一下"放弃本轮" |
| 授权要手打 `1/2/3` 或 `y/n` | **方向键**选的模态框；`1/2/3` 仍可用；飞行过来的回车不算数 |
| 改权限要打 `/permission write` | `Shift+Tab` 沿 readonly→write→full 转，进 `full` 要按两次 |
| 补全菜单只在装了 prompt_toolkit 时才有 | 菜单是模型（`ui/ace_menu`），界面里是输入框上方的浮层 |
| 键位靠记 | `F1` 浮层帮助，内容由键位表**生成**（写着的键一定绑上了） |
| 输出一行一行蹦 | **活尾行**：模型边吐字边上屏，换行才落成正式一行 |

## 为什么中断要分两段（这一条是设计决定，不是实现细节）

一下就把线程扔掉，会留下"工具跑了一半、快照不一致、会话日志停在中间"的烂摊子 ——
那不是响应快。所以：

- **第一次**（`requested`）：设停机位，引擎在**轮边界**和**工具执行前**检查 ——
  停在"一个工具之前"是最干净的落点，能拿到半截结果；
- **第二次**（`forced`）：界面立刻回到可用，并在左下角如实说明"后台线程仍在收尾，
  它的输出不再上屏"。

## 作用域键位与和弦

- `Esc` 在输入框 / 浮层 / 对话框 / 会话区是四件事，由一张表决定（可断言），不是"什么都做一点"。
- 低频操作走**和弦**：`Ctrl+X` 然后 `e`=全部展开 / `t`=任务树 / `d`=本轮改动 ——
  不跟常用键抢 `Ctrl+字母`（真实终端里能用的本来就没剩几个）。
- 第二段不认识时**不吞键**，超时作废：吞键就是"我按了没反应"。

## 默认界面

装了 Textual 且是**真终端**时，默认就是组件界面；`--no-tui` 退回普通 REPL。
`--json` / `--input` / `--preview` 与管道一律不进全屏（机器可读输出不该被劫持）。

```bash
python setup_env.py --ensure      # 装好界面依赖（仓库自带离线 wheel）
python ai_code.py                 # 直接进组件界面
python ai_code.py --no-tui        # 想要逐行滚动的那种
```

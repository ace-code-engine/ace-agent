## 转录口径与不确定项

1. **「Weekly from 2026年8月5日 to 2026年9月9日」与 x 轴末端「Sep 21」不一致。**
   这是 GitHub 在自定义区间下的实际显示。本包**不推断**哪个才是真实区间 —— 两者都照录，引用时请注明"页面如此显示"。

2. **柱高是目测读数**，不是页面给出的数字。页面只在贡献者卡片上给出精确计数（`156 / 38,776 / 8,221`）。
   **写文章请引用精确计数，不要引用柱高。**

3. **`156 commits` 与 git 的 `284 commits` 不是同一口径**，二者不能互相印证，也不能互相否定：

   | | 本页 | `RAW/repo_meta.txt` |
   |---|---|---|
   | 计数 | **156** | **284** |
   | 范围 | 所选区间内 | 全部历史 |
   | 是否排除 merge | **排除** | 不排除 |
   | 分支 | `main` | `HEAD` |
   | 出处 | 本页截图 | `git rev-list --count HEAD` |

4. **本页不含仓库维度**：它统计该账户的贡献，**不显示属于哪个仓库**，也不显示组织归属。
   因此**不能**用它证明「该仓库由个人账户转移而来」—— 那个结论的出处是 `RAW/transfer_evidence.txt`（commit hash 相同 + 301 重定向 + 仓库 id 相同）。
